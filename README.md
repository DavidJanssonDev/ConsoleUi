# ConsoleUi

![.NET](https://img.shields.io/badge/.NET-10-blue)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey)
![Status](https://img.shields.io/badge/status-experimental-orange)

ConsoleUi is an experimental **.NET console UI framework** focused on
**framebuffer-style rendering**, **layout**, and **high-performance logging UIs**.

The terminal is treated like a low-level graphics surface:
layout is computed explicitly, rendered into a buffer, and presented in one step.

## ✨ Highlights

- Framebuffer-based rendering
- Deterministic layout engine
- Async non-blocking logging
- Dedicated log viewer UI
- Designed for cross-platform growth

---

## 🚀 Quick Start

1. Run **ConsoleUi.Logger**
2. Run **ConsoleUi.Demo**
3. Resize the console window
4. Watch logs render live
